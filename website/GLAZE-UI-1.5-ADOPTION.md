# Continuity Center — Glaze UI 1.5.0 adoption

The Continuity Center targets **Glaze UI 1.5.0 Stable** from `GoreeCloud/goreecloud-glaze-ui` revision `2c5078410d022eba683c8e029bc3cafe773df0b7`. Stable web layers are vendored in the Everkeep website deployment and mapped onto continuity, preservation, recovery, portability, succession, assurance, focus, material, and reduced-motion presentation. Candidate/Wearable layers are excluded.
