# Continuity Center — Glaze UI 2.0.0 adoption

The Continuity Center targets **Glaze UI 2.0.0 Stable** from `GoreeCloud/goreecloud-glaze-ui`, using the promoted 2.0 web contract anchored to Stable promotion reference `ff3fff4306bd53ea9c0715a7c0d64265bb038617`.

The deployed same-origin web layer applies the 2.0 material and interaction model to Continuity Center navigation, actions, identity surfaces, status surfaces, and domain cards while preserving Everkeep’s substantive evidence boundaries. It includes 48px minimum interactive targets, keyboard focus visibility, reduced-motion handling, reduced-transparency solid fallbacks, increased-contrast support, forced-colors support, and non-backdrop fallbacks.

Source and build validation prove the declared 2.0 integration and packaged artifact. Rendered Cloudflare Pages acceptance remains a separate gate and must pass before this migration is treated as production evidence.
